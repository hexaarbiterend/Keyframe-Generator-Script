## `ABOUT`

Script that **generates keyframe data files** for zoom, pan, and shake animations to paste into video editor projects.

## `FEATURES`

🔢 **Math-based curves** — Smooth zoom and easing without manual keyframing.
📳 **Shake presets** — Lightweight, medium, and heavy camera shake templates.
📄 **Text / JSON export** — Drop output into your editor workflow.
🎞️ **FPS-aware** — Generate keys matched to project frame rate.
⚡ **One command** — PowerShell handles download, unpack, and setup.
